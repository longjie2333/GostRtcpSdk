# v0.1.0-alpha.1

首个预览版，适用于 Go 1.23+。模块路径已更正为 `github.com/longjie2333/GostRtcpSdk`，SDK 导入路径为 `github.com/longjie2333/GostRtcpSdk/src`。

## 安装

```shell
go get github.com/longjie2333/GostRtcpSdk/src@v0.1.0-alpha.1
```

```go
import rtcp "github.com/longjie2333/GostRtcpSdk/src"
```

使用 GitHub 模块路径，不保留旧本地占位模块的兼容入口。SDK 使用方无需 replace；仓库内 Gin 示例和外部模块测试的 replace 仅用于验证当前 checkout。

## 包含的能力

- 连接官方 GOST v3.3.0 的 Relay+TLS 服务端，提供单节点 TCP 客户端 SDK。
- `Client.Run` 转发到 TCP 目标，`Client.UpdateTarget` 并发安全地更新新连接目标。
- `Listen(ctx, cfg)` 返回标准 net.Listener，将连接直接交给业务，无需本地监听端口；可接入 Gin、net/http 或自定义 TCP 服务。
- 支持远端分配端口、访客地址、断线重连、请求排空及 context 取消。
- 提供独立 Gin 示例；SDK 本身仅依赖 relay v0.7.0、smux v1.5.31 和 Go 标准库。

## 预览边界

- 仅提供客户端 TCP 能力，不包含公网服务端、UDP 或通用代理框架。
- `TLS=nil` 沿用源版本默认不验证证书；需要身份验证时显式设置 `Config.TLS`。
- 绑定地址需显式填写主机，如 `0.0.0.0:8080`，不使用 `:8080`。
- 原复制循环与半关闭限制保留；断线不会恢复旧连接，动态端口重连后可能变化。详见 [行为说明](https://github.com/longjie2333/GostRtcpSdk/blob/v0.1.0-alpha.1/docs/behavior.md)。

预览发布工作流对该标签的代码执行格式、两个 module 的 tidy/build/vet/race 测试、外部 Go module 引用验证及官方 GOST v3.3.0 互通检查；完整检查禁止跳过测试。发布为 GitHub Pre-release，不标记为稳定版或 latest。
